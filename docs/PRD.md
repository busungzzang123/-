# PRD: 냉장고털기

## 목표
집/사무실에 있는 재료를 등록하면 AI가 그 재료로 만들 수 있는 레시피를 추천해주는, 로그인 없는 공유 냉장고 서비스

## 사용자
같은 공간(팀, 가족, 기숙사 등)에서 냉장고를 함께 쓰며 재료를 등록하고 레시피 추천을 받는 사람들. 사용자 구분·로그인 없이 전체가 하나의 냉장고를 공유한다 (팀 전체가 보는 공용 냉장고 개념).

## 핵심 기능
1. 냉장고 재료 관리 — 재료 추가(이름+양), 전체 목록 조회, 삭제
2. AI 레시피 추천 — 인분수를 입력하면 현재 냉장고 재료 전체와 최근 피드백 3개를 반영해 Gemini가 레시피(가능 여부 `feasible`, 사유 `note`, 조리 단계 `steps`)를 추천
3. 레시피 후기 — 추천받은 레시피에 대해 "좋았음"/"별로였음" + 선택 코멘트를 남기고, 이후 추천 시 참고 자료로 반영

## MVP 제외 사항
- 로그인/회원가입 및 사용자별 냉장고 구분 (전체가 공유하는 냉장고 하나만 존재)
- 재료 자동 병합/수량 계산 (같은 이름이어도 별도 항목으로 저장, 수량은 자유 텍스트 그대로 AI가 텍스트로 합산 이해)
- 레시피 이미지 생성, 재료 사진 인식(OCR) 기반 등록
- 사용자별 피드백 개인화 (전체 피드백 중 최근 3개만 참고, 작성자 구분 없음)
